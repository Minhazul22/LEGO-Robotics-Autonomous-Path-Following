# Project media

Add approved photographs and a short video of the real robot to this directory.

Suggested filenames:
- `robot-on-course.jpg`
- `path-following-demo.mp4`
- `flag-collection.jpg`
- `course-layout.png`

Example embed in the root README:

```markdown
![EV3 robot on the competition course](media/robot-on-course.jpg)
```

Use actual project media and accurate captions. Do not use stock images as evidence of your specific robot. Make sure you have permission to publish images/videos and remove private information.
