# Robot source code

The original competition Python code is unavailable. The file `line_following_example.py` is an illustrative `ev3dev2` starter, not a copy of the program used at the competition.

Before use, verify the EV3 operating system, install the matching EV3 Python library, confirm sensor/motor ports, calibrate sensor readings against the actual surfaces, and test safely at low speed. The example is not guaranteed to detect green directly.
